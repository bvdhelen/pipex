WIFEXITED y WEXITSTATUS

Cuando un proceso hijo termina 
(ya sea de forma normal, porque llamó a exit(), 
o de forma anormal, porque fue terminado por una señal),
el proceso padre que lo espera (waitpid) recibe 
un status (un entero) que contiene información codificada
sobre cómo terminó ese hijo.

Este status es un valor críptico por sí solo. 
No puedes simplemente imprimirlo y esperar entenderlo. 
Para interpretar este entero, el sistema operativo POSIX 
proporciona un conjunto de macros 
(funciones especiales que se expanden en tiempo 
de compilación) que extraen la información relevante.

1. WIFEXITED(status)

    ¿Qué hace?
	Esta macro te dice si el proceso hijo terminó
	de forma normal. Es decir, si el hijo llamó a 
	exit() o simplemente retornó de su función main().

    Valor de retorno:
	Devuelve un valor verdadero (distinto de cero)
	si el hijo terminó normalmente, y falso (cero)
	si no lo hizo (por ejemplo, si fue terminado
	por una señal, como un SIGSEGV).

    ¿Por qué es importante?
	Antes de intentar obtener el código de salida,
	necesitas saber si el hijo realmente salió
	de forma "limpia". Si fue terminado por una señal,
	intentar obtener un código de salida normal
	no tiene sentido.

2. WEXITSTATUS(status)

    ¿Qué hace?
	Si WIFEXITED(status) te dice que el hijo terminó
	normalmente, esta macro te permite extraer
	el código de salida real que el hijo proporcionó
	a exit() o que devolvió desde main().

    Valor de retorno:
	Devuelve un entero, que es el código de salida
	del proceso hijo. Este valor estará en el rango
	de 0 a 255. Un código de 0 generalmente indica éxito,
	mientras que cualquier otro valor indica 
	algún tipo de error.

    ¿Por qué es importante?
	La shell (y, por lo tanto, tu pipex) debe replicar
	el comportamiento de los comandos.
	Si un comando como grep no encuentra nada,
	sale con 1. Si un comando no existe,
	la shell sale con 127. Para que tu pipex sea fiel
	a la shell, debes adoptar el código de salida
	del último comando de la tubería.
